# 校园连续剧《7班班长的奇妙旅程》第三季第一集（S3E1）分镜头脚本

**剧集名称**：《7班班长的奇妙旅程》第三季第一集《全员住校》
**比例**：16:9
**总时长**：约13分30秒（按每个镜头5秒或10秒严格计算）
**场景数**：6场（含开场）
**镜头总数**：约86个镜头


## 本集新增固定场景

| 场景 | 功能 |
|------|------|
| 七班男生宿舍（401） | 江浩、陈宇、赵磊、林屿四人间——夜谈/冲突/沉默的发生地 |
| 七班女生宿舍（306） | 许星遥、沈砚舟、林舒晏、夏若桢四人间——周淼的8号床位永远空着 |
| 宿舍走廊 | 半夜背书的人、打电话的人、哭泣的人 |
| 食堂 | 非正式交流、崩溃时刻、集体用餐 |
| 宿管值班室 | 借电话、借充电器、被没收的零食 |

## 本集核心表达落点

1. **“删除走读生”的冲击力**：
   - 通知在开学前三天才发，全家措手不及——行李装箱、情绪没有缓冲期。这个设计让第一集的混乱感是真实的、不是演出来的。全片没有展示“通知发送的画面”，而是用周淼速写本上的手机截图来交代——更简洁、更符合本季“速写本叙事”的基调。

2. **周淼的走读理由：慢性胃病，需在家调理**：
   - 呼应S2E8的胃药瓶伏笔。医生开具了“不适宜长期住校”的建议，学校审核通过。她不住校，但每天中午可以在306休息、课间和所有人在一起——她在“七班”和“家”之间保持了一个平衡。她不是被排除在外，她是唯一一条能通向外面的绳子。

3. **401和306两个宿舍的空间定义**：
   - 男生宿舍401：四张床、四个人、四种不同的生活节奏——但同一扇门。林屿的上铺、赵磊的下铺、江浩的乱、陈宇的沉默——一个房间就概括了四个人的相处模式。
   - 女生宿舍306：三张睡人的床、一张空着的床。周淼的“不在场”是这个房间里最重要的特征——她的名字贴在空床板上，她的人在校外。

4. **第一周的快剪节奏**：
   - 从混乱到适应只需要五天。第五天和第一天的对比不用台词说明——用画面（行李从多到少、从找不到路到熟悉的路径、从整夜翻身到快速入睡）展示。适应不一定愉快，但一定会发生。

5. **食堂阿姨的“番茄炒蛋”**：
   - 江浩想家，食堂阿姨多打了半勺菜。这是全员住校后“替代家庭”的微小瞬间——不是煽情，是真实的“在外面有人接住你的想家”。

6. **周五傍晚的校门**：
   - 所有人都急着离开，周淼是唯一一个“回头”的人。她回头看了一眼宿舍楼——306的窗开着，沈砚舟在挥手。那个画面被画进了速写本。这是本季第一次明确：周淼虽然能走，但她已经开始“回头看”了。

7. **速写本叙事的第一集落地**：
   - 开场用速写交代通知、中间穿插她画宿舍空床的瞬间、结尾用速写本里的宿舍楼夜景和“还能走多少个周末”收束。速写本在S3不再只是“她画了什么”，而是“她通过画理解自己正在经历什么”。

8. **宿舍公约的喜剧与真实**：
   - 赵磊提前打印的“401公约”是他的性格延续——规则先于生活。江浩看到后的反应是本集最轻松的喜剧点。但公约上“保持安静”那条在后续夜谈集中会变成最大的矛盾点——预告性的喜剧。

9. **倒计时数字首次出现**：
   - 结尾字幕写“还剩293天”——从300天跳到了293，标志着第一周已经过去了。这个数字会在后续每一集中逐渐减少，成为整个S3的视觉锚点。
