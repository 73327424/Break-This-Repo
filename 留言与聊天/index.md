# 校园连续剧《7班班长的奇妙旅程》完整创作方案

## 一、剧集核心定位

**剧名**：《7班班长的奇妙旅程》
**题材**：青春校园、治愈成长、群像日常、轻励志喜剧
**受众**：中小学生、家长、校园青春剧爱好者
**核心主旨**：没有超级英雄，只有普通中学里最靠谱的少年。讲述顶级优秀、全能负责的七班班长，带着一群性格各异、优缺点鲜明的普通同学，在琐碎的初中校园生活里，一起纠错、一起成长、一起守住七班荣光的故事，真实复刻初中三年的热血、遗憾、温暖与治愈。
**风格**：真实接地气、轻松不狗血、治愈有温度，无早恋狗血剧情，主打**同学情谊、班级成长、少年担当、师生日常**

## 二、世界观设定

故事发生在一座城市里最普通的公立初中 ——**启明中学**。这里没有顶配的精英班级，没有开挂的天才人设，只有最真实的初中日常：周测排名、课间打闹、卫生评比、运动会翻车、月考压力、班级矛盾、师生斗智斗勇。

而**初二七班**，是启明中学最特殊的普通班级：不是重点尖刀班，没有特殊优待，却常年霸占年级团体总分前三、文明班级榜首，是全校老师最放心、全校学生最佩服的 “神仙普通班”。这份光鲜的背后，一直靠着全能靠谱的七班班长默默支撑。

## 三、核心人物设定

### 主角：七班班长（林屿）

**年级**：初二、蝉联两年校级优秀班长
**核心标签**：全校顶尖学霸、全能才艺、极致负责、温柔有原则、外稳内热
**详细人设**

1. **学业能力**：常年稳居年级前十，文理均衡无短板，擅长总结学习方法，会帮后进生定制补习计划，考试从不内卷自私，主动分享笔记和解题技巧，是全校公认的 “人形题库”。

2. **全能才艺**：学校文艺汇演常驻主力，钢琴、硬笔书法、朗诵、辩论赛全能拿捏；运动会可替补接力、跳远，文武双全，不是书呆子型学霸。

3. **性格特质**：极度有责任心，把班级荣誉刻在心里，班里大小事全包：管纪律、盯卫生、帮同学、对接老师、处理矛盾；外表冷静沉稳、做事条理清晰，从不急躁，内心温柔细腻，懂得包容同学的缺点，有底线、不软弱，遇事先解决问题，不抱怨不甩锅。

4. **小反差萌**：看似完美无短板，唯独有点轻微 “班级强迫症”，见不得七班扣分、掉队、乱糟糟；偶尔会因为操心太多偷偷疲惫，但从来不会在同学面前表露。

### 七班核心配角（班级群像，全员普通人设，真实鲜活）

1. **副班长 江浩**：典型乐天派学渣，性格仗义、人缘极好，体育满分，是班级气氛担当。不爱学习但最服班长，是班长的 “武力兼嘴替辅助”，专门帮班长镇住调皮同学、化解尴尬，缺点是容易冲动闯祸，经常需要班长兜底。

2. **学习委员 陆景珩**：文静细心，文科极强、理科偏弱，极致认真严谨，擅长整理资料，是班长的最佳学业搭档。性格有点内向敏感，遇到矛盾容易纠结，需要班长开导鼓励。

3. **纪律委员 赵磊**：死板耿直、认死理，只会按规矩办事，经常和调皮同学起冲突，不懂变通，常常需要班长从中调和，慢慢学会温柔管理。

4. **调皮同桌 陈宇**：班级 “捣蛋鬼”，聪明但懒散、爱摸鱼、上课走神、经常扣分，是班里的重点管控对象。看似叛逆，实则内心渴望被关注，被班长耐心包容、一点点改变，是全剧成长线最明显的角色。

5. **佛系转学生 周淼**：安静寡言、不爱合群，成绩中等，有点自卑，刚转来七班时格格不入，在班长的主动接纳和班级温暖中，慢慢打开心扉、融入集体。

6. **老班（王老师）**：七班班主任，语文老师，温柔开明、不刻板，信任班长，懂得放手让孩子成长，不唯成绩论，是全班的后盾，偶尔会和班长双向奔赴、互相治愈。

### 次要配角

- 年级学霸对手（8班班长）：成绩和班长不相上下，好胜心强，经常和七班比拼，亦敌亦友，良性竞争共同进步；

- 调皮小团体：爱打闹、爱扣分、不爱集体，是班级日常管理的主要难题；

- 各科任课老师：风格各异，严厉、幽默、佛系全覆盖，复刻真实校园师生关系。

## 四、全剧整体剧情大纲（三季・对应初中三年）

### 第一季：初一・初遇集结（20 集）

**核心主题**：磨合、接纳、建立班级归属感
讲述刚升入初中的林屿当选七班班长，面对一群互不熟悉、性格迥异的陌生同学，从混乱的新生班级开始，一点点立规矩、聚人心。解决新生磨合矛盾、宿舍矛盾、开学分班不适、后进生抵触管理、班级首次评比翻车等问题，从零打造出初具凝聚力的七班，奠定 “团结靠谱” 的班级底色。

### 第二季：初二・逆风成长（30 集）【核心高光季】

**核心主题**：突破、担当、并肩成长
初二是初中分水岭，学业难度暴涨、同学心态分化。七班迎来最大危机：成绩两极分化、调皮学生频繁违纪、隔壁班级恶意比拼、运动会失误扣分、文艺汇演翻车、月考集体滑坡。
班长不再是单纯的 “管人者”，而是带领全班复盘问题、分层补习、化解矛盾、团结人心，带着优缺点各异的同学们逆风翻盘，让普通的七班一次次创造惊喜，全员实现不同程度的成长。

### 第三季：初三・奔赴盛夏（30 集）

**核心主题**：拼搏、告别、青春圆满
备战中考的高压日常，刷题、模考、排名压力、升学焦虑席卷全班。有人迷茫摆烂、有人奋力追赶、有人面临择校难题。
班长顶住自身学业压力，安抚全班心态，组织互助小组、百日誓师、班级解压活动，带领七班平稳度过最难的初三时光。最终全员奔赴中考，收获成长与友谊，圆满告别三年初中青春。

## 五、经典单集小故事（可直接拍摄，单集独立完整，串联主线）

1. **第一集《新班长的第一堂课》**：开学班级乱糟糟，没人愿意配合纪律管理，多个同学随意讲话、打闹，老师任命林屿为班长。初次上任的他不凶不吼，用温和又坚定的方式稳住全班，第一次让松散的七班安静下来。

2. **《扣分危机》**：陈宇课间追逐打闹导致班级扣分，文明班级评选岌岌可危，全班抱怨指责。班长没有追责骂人，而是主动带陈宇认错、弥补过错，同时安抚全班情绪，告诉大家 “扣分可以补，团结不能散”。

3. **《差生的补习计划》**：月考后班级后进生集体垫底，七班年级总分滑落。班长放弃课余时间，根据每个人的短板定制专属补习方案，组织班级互助小组，利用午休、自习课带领大家查漏补缺。

4. **《运动会的遗憾与翻盘》**：七班主力选手失误弃权，大家心态崩盘、全员摆烂。班长临时替补参赛，同时鼓励所有人坚持到底，哪怕拿不到名次，也要拼完最后一场，让全班懂得集体荣誉的意义。

5. **《转学生的小世界》**：新转来的周淼孤僻自卑，被同学无意孤立，独自独处。班长主动关注她的情绪，邀请她参与班级活动、组队学习，帮她融入集体，治愈内向少年的孤独。

6. **《班长也会累》**：连续熬夜管班级、帮同学补习、处理琐事，全能班长第一次疲惫走神，小测失利、管理失误，被同学质疑 “多管闲事”。这一集解锁班长的脆弱面，大家才发现完美班长也在默默负重，全班反向守护班长。

7. **《班级辩论赛》**：年级辩论赛，七班没人敢报名，全员退缩。班长带头组队，熬夜陪队员训练、打磨稿子，从零基础一路逆袭，打败常年夺冠的精英三班。

8. **《师生和解日记》**：班级因为集体松懈被班主任批评，全班赌气抵触老师。班长双向沟通，化解师生误会，让大家懂得老师的严厉都是期许。

9. **《期末的双向奔赴》**：期末将至，全班主动自觉学习、遵守纪律，不再让班长操心。曾经最调皮的同学主动帮忙管纪律、整理教室，所有人用自己的方式回报默默付出的班长。

## 六、剧集核心亮点（区别于烂俗校园剧）

1. **零狗血、零早恋**：全程聚焦**少年成长、班级友谊、责任担当、学习奋斗**，适合全年龄段观看，正能量满满。

2. **极致真实接地气**：没有悬浮剧情，所有故事都是初中生真实经历：扣分、周测、自习、跑操、同学矛盾、老师唠叨、考试焦虑，代入感极强。

3. **主角人设讨喜不圣母**：班长完美但不虚假，温柔但有底线、负责但不矫情、包容但不纵容，有高光也有疲惫，真实立体。

4. **全员成长群像**：不止主角优秀，每一个普通同学都有蜕变，调皮的变懂事、自卑的变开朗、懒散的变努力，人人都是主角。

5. **治愈轻励志**：不强行鸡汤，用日常小事传递道理：普通的班级、普通的少年，只要团结努力，就能活出不普通的青春。

## 七、剧集拍摄 \& 呈现建议

1. **时长**：单集 10\-15 分钟，短剧节奏，剧情紧凑不拖沓；

2. **画质色调**：清新暖色调，明亮治愈，贴合校园青春感；

3. **台词风格**：口语化、生活化，不用华丽台词，还原初中生真实对话；

4. **核心镜头**：多捕捉班级集体画面、课间日常、自习细节、师生互动，突出 “七班大家庭” 的氛围。
