### 九集结构总览

| 集数 | 标题 | 核心主题 |
|------|------|----------|
| EP1 | 新班长的第一堂课 | 班长的"初登场"——温柔但坚定 |
| EP2 | 渐入佳境 | 从"一个人扛"到"有帮手" |
| EP3 | 人形题库 | 学霸能力展示·知识共享 |
| EP4 | 文化墙上的七班 | 班级凝聚力可视化 |
| EP5 | 班委天团 | 七科课代表+赵磊上线 |
| EP6 | 七班的大戏 | 全班共同的高光时刻 |
| EP7 | 最后一战 | 期末复习·第一季收官 |
| EP8 | 差生的补习计划 | 后进生专项帮扶·全员逆袭 |
| EP9 | 双向奔赴 | 全班回报班长·第一季圆满 |

### 本集核心表达落点

1. **"双向奔赴"的真正含义**：
   - 不是班长单向付出换来全班感激，而是班长在付出的过程中把"责任感"传递给了每个人——最终全班用自己的方式撑起了班级，让班长"无事可做"。这才是"双向奔赴"的本质：**你把别人变好了，别人把你变得不必那么累了。**

2. **"第七颗星"的集体创作**：
   - 前面的星星都是某个人画的，但第七颗是"全班一起画的"。这是整季视觉符号的最高完成度——从"一个人的标记"变成了"所有人的行动"。

3. **"一"字的留白**：
   - 林屿画了一颗超大星星和"一"字。不是"第一"，是"第一年"——意味着还有第二年、第三年。这是给未来留的钩子，也是最克制的"续集预告"。

4. **每个人的"还礼"设计**：
   - 七个课代表各自用自己的方式"还"给班长——誊笔记、速查表、薄荷糖、补提纲、写列传、画地图、送绿萝。这些礼物都恰好对应每个人的人设（江亦扬写字工整、许星遥逻辑狂魔、沈砚舟活泼、赵硕爱操心、季承屹爱写故事、夏若桢会画画、林舒晏养植物），不是硬凑的。

5. **陈宇的"一盒笔"**：
   - 从第一集陈宇撞人扣分、到第九集他主动花钱给班长买笔——这是他整季成长线的最终闭环。他不说"谢谢"，但用行动说完了所有话。

6. **赵磊的"我跟上了"**：
   - 四个字，是赵磊整季的总结：从"只会记名字"到"我同意"到"我跟上了"——跟上了班级的温度、跟上了一起成长的节奏。

7. **王老师的彩蛋**：
   - 最后王老师画外音说"我没错看"，呼应了第一集她任命林屿为班长的第一个镜头——"你就是那种会把别人也变好的人"。首尾完整闭环。

8. **"最好的七班"——不是"最优秀的七班"**：
   - 江浩最后写的不是"最厉害"或"最成功"，而是"最好"。这是整季的价值观落点——七班没有拿过年级第一，文化墙第一但总分第三，运动会第三名，月考从第八回到第四——但"好"不等于"第一"，七班是普通班里的"最好"，因为每个人都在变得更好。
